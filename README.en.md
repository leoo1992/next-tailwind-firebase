# Next.js, Tailwind CSS, and Firebase

A study project combining Next.js, React, and Tailwind CSS with Firebase integration. The code provides a base for experimenting with web pages and Firebase-backed features.

## Stack
- Next.js and React
- TypeScript
- Tailwind CSS
- Firebase

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000. Configure the Firebase environment variables required by the source before testing service-dependent features.
