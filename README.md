# Next.js, Tailwind CSS e Firebase

Projeto de estudo que combina Next.js, React e Tailwind CSS com integração ao Firebase. O código serve como base para experimentar páginas e recursos web conectados a serviços Firebase.

## Stack
- Next.js e React
- TypeScript
- Tailwind CSS
- Firebase

## Como executar

```bash
npm install
npm run dev
```

Acesse http://localhost:3000. Configure as variáveis Firebase exigidas pelo código antes de testar recursos que dependem do serviço.
